# StageVoice website

The public marketing site for StageVoice, a teleprompter that follows your
voice: https://angelosramdas-afk.github.io/stagevoice-site/

Plain HTML/CSS/JS with no build step. The source of truth is the `website/`
folder in the (private) app repository; this repo is a published copy of it.
Every push to `main` deploys to GitHub Pages via `.github/workflows/deploy.yml`.
